# Classic GAP kernel policy skin and bind

Live kernel policies may be JSON-encoded GAP instructions and YAML remains valid GAP source because the kernel reads the instruction object not the skin. Writing and security are always-on stems so they evaluate on every action_path. Other GAP walls bind to a wrap or an action_path prefix. A finance wrap GAP item does not close an inventory wrap ping. A non-always-on GAP with empty wrap does not fold onto every event. AEP 2.8.5 reference policies are JSON objects with pattern.guard and policy-system GAP walls bind to LatticeNode.wrap or an action_path prefix. Keep `.gap` as GAP source and do not edit GAPLUNE trees for this ticket. Crate aep-gap-kernel-json-wrap-bind implements GAP-285-P5.
